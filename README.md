# TransferCompare

An international money transfer comparison web application built with React, TypeScript, Vite, Tailwind CSS, and shadcn/ui.

## Features

- Compare real-time transfer quotes across multiple providers (exchange rate, fees, delivery time, and net amount received)
- Filter results by payout method (Bank Deposit, Cash Pickup)
- Live USD exchange rate snapshot via `open.er-api.com`
- Responsive UI with dedicated informational and legal pages

## Tech Stack

- Vite + React + TypeScript
- Tailwind CSS + shadcn/ui (Radix UI)
- React Router v6 + TanStack Query

## Local Development

```sh
# Install dependencies
npm install

# Start the development server
npm run dev

# Run linter
npm run lint

# Build for production
npm run build
```
